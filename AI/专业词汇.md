### 欠拟合和过拟合

#### 欠拟合

训练的数据过少，导致学习的东西压根没记住，通俗理解就是学不透

#### 过拟合

训练的数据过于复杂，导致学习的时候连同噪声也记下了，对数据规律的捕捉能力不足或者过度，通俗理解就是死记硬背，体现是在训练集表现优异，但是测试集表现不佳

#### 对比

两者对比就像是一个三角函数的推演，欠拟合使用的是一个一次函数，而过拟合使用的是一个高阶多项式处理

#### 处理方式

* 欠拟合
  * 增加模型的复杂度，例如使用项数更高阶的多项式，更深的神经网络，优化特征工程，减少正则化等
* 过拟合
  * L1和L2正则化，对江大的权重进行惩罚
  * 早停法，确保不会过度训练模型
  * dropout技术，随机让一些神经元停止工作

### 有监督学习和无监督学习

#### 监督学习

supervised learning

通过观察输入x和期望输出标签y的正确配对

概括为两类

* 回归
* 分类

#### 无监督学习

unsupervised learning

找到某种结构或模式，让算法自己找出规律或者存在的模式

分成三类

* 聚类算法 - 将个体分成不同的类别或不同的类型
* 异常检测 - 寻找异常的数据点（反欺诈）
* 降维技术 - 将数据集压缩成更下的数据集



### 训练集

### 线性回归

Linear Regression

univariable linear regression 

如果要线性回归起作用，必须构建一个成本函数cost function



### 成本函数（代价函数）

告诉我们模型的表现如何

F(x) = wx + b

* w - coefficients
* b - weights
* slope - 斜率

成本函数是m个预测值和实际值差值的平方和除以2m，一般用 J(w,b)表示成本函数，J(w,b) 越小，拟合的越好



### 梯度下降

找到最合适的w和b

w = w - a (a/aw) J(w, b)

* a - 学习率 learning rate
  * 通常是介于0 ~ 1之间的小正数，控制下坡的步长
* (a/aw) J(w, b) - 成本函数 J 的导数项，步长方向 derivative

b = b - a (a/ab) J(w, b)

如果w和b不在随着才去的每一步而显著变化，则说明函数收敛了

注意，w 和 b 都是同时变化的
